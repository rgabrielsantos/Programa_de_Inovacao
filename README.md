🚀 Projeto DAX Code - 2ª Edição
Bem-vindo(a) ao repositório que documenta minha jornada no Projeto DAX Code, uma iniciativa de impacto social promovida pela DAX OIL REFINO S.A. em parceria com o CAEC (Centro de Apoio aos Esportes e à Cidadania)
.
O projeto utiliza a Metodologia DAXCoder, focada em Learning by Doing (aprendizado prático), integrando tecnologia, desenvolvimento humano e vivência profissional
.
📚 Sobre o Programa
O curso possui uma carga horária total de 288 horas ao longo de 7 meses, preparando profissionais para os desafios reais do mercado de tecnologia
. A formação é dividida em eixos técnicos, transversais e integradores
.
🛠️ Habilidades Técnicas (Hard Skills)
🌐 Desenvolvimento Web Full Stack
Capacidade de transformar ideias em sistemas funcionais utilizando:
Front-end: HTML5, CSS3, JavaScript (ES6+), e o framework React com foco em componentização e manipulação do DOM
.
Back-end: Desenvolvimento de APIs em PHP e integração com banco de dados MySQL
.
DevOps/Ferramentas: Versionamento com Git e hospedagem de portfólio no GitHub
.
📱 Desenvolvimento Mobile
Criação de aplicativos para celular utilizando o framework React Native
.
Consumo de APIs e implementação de navegação entre telas e gerenciamento de estado
.
🧩 Fundamentos e Planejamento
Pensamento Computacional: Domínio dos 4 pilares (decomposição, reconhecimento de padrões, abstração e algoritmos)
.
Mentalidade de Projetos: Pesquisa, análise de requisitos, gestão do tempo e organização de escopo
.
Inglês Técnico: Vocabulário essencial para leitura de documentações e comandos em programação
.
🧠 Habilidades Socioemocionais (Soft Skills)
Além do código, o programa foca no desenvolvimento integral do profissional
:
Comunicação e Colaboração: Trabalho em equipe e resolução de problemas
.
Ética e Responsabilidade: Atuação profissional pautada no respeito e inclusão
.
Empreendedorismo: Pensamento crítico e criatividade para propor soluções inovadoras
.
🏗️ Projetos e Entregas (Hands-on)
Durante a formação, foram desenvolvidos diversos artefatos práticos no Laboratório de Projetos Reais
:
Portfólio Individual: Site estático com deploy realizado no GitHub(em desenvolvimento)
.
API Funcional: Com rotas e persistência de dados(em desenvolvimento)
.
Projeto Final (Full Stack): Uma solução completa integrando as versões Web e Mobile à mesma API (em desenvolvimento)
.
🏆 Certificação e Critérios
A conclusão do curso exige não apenas a entrega técnica, mas também compromisso com a excelência, mantendo frequência mínima de 75% e média de aproveitamento superior a 6.0
.
