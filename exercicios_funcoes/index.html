Exercitando funções

Questão 1:

Crie uma função normalizarNome(nome) que:
- receba um nome como "jõao da silva";
- remova os espaços extras do início e do fim com trim();
- divida o nome em partes usando split();
- percorra as partes com forEach();
- transforme cada parte para começar com letra maiúscula usando slice();
- retorne o nome completo formatado.
Depois, use a função em um array de nomes e exiba os resultados.

Questão 2:

Considere o array:
const produtos = ["Notebook - eletrônico","Mouse - Eletrônico","Cadeira - Móvel", "Teclado - Eletrônico","Mesa - Móvel"];
Crie um filtro em que a pessoa consiga usar um select para selecionar a categoria do produto (eletrônico ou móvel) e seja exibido uma imagem e o nome do produto. Use uma função que faça a filtragem do array com base na categoria informada.
